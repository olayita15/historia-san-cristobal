# Sesión de estudio · Historia de San Cristóbal

Presentación Slidev basada principalmente en `../Investigación profunda_.docx`.

## Ejecutar

```bash
npm run dev
```

## Publicar en GitHub Pages

El flujo `.github/workflows/deploy-pages.yml` publica automáticamente cada cambio enviado a `main`.
La compilación usa la base `/historia-san-cristobal/`, necesaria para que las imágenes y recursos funcionen dentro del proyecto de GitHub Pages.

## Estructura

- `slides.md`: guion, contenido y notas del orador.
- `style.css`: sistema visual y animaciones globales.
- `public/slides/NN-slug/`: imágenes, mapas y recursos propios de cada diapositiva.
- `public/slides/NN-slug/README.md`: fuente, crédito y pendiente de cada recurso.

## Estructura narrativa

1. **Poblaciones indígenas y territorio originario:** agua, bosque, arqueología regional Herrera–Muisca y presencia indígena contemporánea en Bogotá.
2. **Colonización española y haciendas:** concentración de la tierra, transformación ambiental y parcelación rural.
3. **Barrios obreros y migración campesina:** Vitelma, Villa Javier, Veinte de Julio, desplazamiento, autoconstrucción, reconocimiento institucional y organización social.
4. **Época contemporánea y dinámicas locales:** Entrenubes, movilidad, ambiente, servicios y derecho a la ciudad.

La presentación separa evidencia arqueológica regional, historia territorial documentada y memoria social para no presentar como certeza aquello que requiere mayor investigación local.
